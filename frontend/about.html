About

An evidence-grounded assistant for tree planting in Thatta, Sindh. It answers only from a small set of documents, shows the page behind every claim, and says so when the documents do not answer the question.

How an answer is made

  1. Search. The question is matched against the documents by meaning and by keywords, and the two result lists are combined and re-ranked.
  2. Evidence check. If no passage is relevant enough, the assistant stops and answers "Evidence unavailable". The language model is not called with empty evidence.
  3. Answer from passages. A language model writes the answer using only the retrieved passages, with a citation for every claim.
  4. Automatic checks. The answer is checked for missing citations, mixed answer types and misspelled scientific names. Table footnotes and the kind of each source (survey or pot experiment) are added by the program, not by the model.

The embedding, re-ranking and language models are pre-trained models that this project connects. No model was trained here.

Limits you should know

  • Check the cited page before you plant. This is not professional forestry or soil advice.
  • A list in an answer can be incomplete when it is drawn from a long table. Open the cited page to see the full table.
  • Map values are gridded estimates, not field measurements. Climate comes from a coarse grid (about 50 km) and soil from a 250 m map. Where the exact soil pixel has no data, the nearest valid pixel within about 300 m is used and the distance is shown.
  • Soil salinity (EC) is not available from the map data. Ask the assistant about salinity: it answers only from the documents.
  • The national guideline is not specific to Thatta, and it does not say which zone Thatta belongs to. Annex 3 salinity levels (Low, Medium, High) have no numeric definition, and a Low level does not mean a species is unsuitable.
  • The district boundary is the Thatta polygon from geoBoundaries (ADM2). District boundaries have changed over time, so check that it matches the area you need.
  • Retrieval and answers were tuned on a 45-question development set whose questions were written while looking at the system's output. On a separate 20-question held-out set, 16 passed the pre-written checks. The misses were two incomplete list answers, one question refused although the documents partly answer it, and one case where the checker, not the assistant, was wrong. Twenty questions are too few for a precise accuracy figure.
